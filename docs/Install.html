Установка в три шага

Терминал и инструменты разработки не нужны. Установите ChatGPT или Codex и войдите в свой аккаунт.

  1. В окне открытого DMG перетащите ChatGPT Limits на папку Applications («Программы»).
  2. Откройте папку «Программы» и запустите ChatGPT Limits. Затем извлеките диск ChatGPT Limits в Finder.
  3. Разрешите уведомления. В строке меню сверху появится GPT с остатком лимита. Нажмите на него, чтобы открыть подробности.

Приложение работает в строке меню, без отдельного окна в Dock. Автозапуск можно отключить в его панели. Если macOS попросит разрешить объект входа, подтвердите это в системных настройках.

Если macOS заблокировала запуск

Текущий пакет ещё не подписан сертификатом Developer ID и не прошёл проверку Apple. Если вы доверяете источнику, после попытки запуска откройте «Системные настройки → Конфиденциальность и безопасность» и используйте доступное действие «Всё равно открыть». Не отключайте защиту macOS целиком. Подробнее у Apple.

Обновление и удаление

Перед заменой старой версии выберите «Выйти» в меню индикатора. Скопируйте новое приложение в ту же папку и подтвердите замену. Если старая копия находится в вашей личной папке «Программы», обновляйте её там, чтобы не создавать вторую копию.

Для удаления отключите «Запускать при входе», выберите «Выйти» и переместите приложение в Корзину.

English

Install in three steps

No Terminal or developer tools required. Install ChatGPT or Codex and sign in to your account first. The monitor's interface is currently in Russian.

  1. In the opened DMG, drag ChatGPT Limits onto Applications.
  2. Launch ChatGPT Limits from Applications, then eject the ChatGPT Limits disk in Finder.
  3. Allow notifications. Click GPT in the menu bar to see your limits. There is no Dock window.

Launch at login is enabled on first start; you can turn it off in the app panel. Approve the login item in System Settings if macOS requests it.

This package is not Developer ID signed or notarized yet. If macOS blocks it and you trust the source, use the available Open Anyway action in System Settings → Privacy & Security after attempting to launch it. Do not disable Gatekeeper globally. Apple's instructions.

Before updating, quit the monitor and replace it in the same Applications folder. If your previous copy is in your personal Applications folder, replace it there to avoid duplicates. To uninstall, disable launch at login, quit, and move the app to Trash.
