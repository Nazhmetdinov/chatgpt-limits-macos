# ChatGPT Limits 1.3.6

Индикатор лимитов ChatGPT Work / Codex в строке меню macOS. Поддерживает Plus и Pro; интерфейс на русском. Независимый неофициальный проект под лицензией MIT.

## Скачать и установить

Скачайте **ChatGPT-Limits-v1.3.6-macOS-universal.dmg**, откройте его и перетащите приложение в Applications. Один установщик для Apple Silicon и Intel. Нужны macOS 13+ и установленный ChatGPT или Codex с выполненным входом. Для альтернативной установки есть ZIP; исходники и контрольные суммы SHA-256 приложены отдельно.

## Возможности

- Остаток лимита в процентах, время до сброса и доступные дополнительные сбросы.
- Отдельные периоды Plus и параметры Pro, полученные от сервиса.
- Уведомления: остаток ниже 10%, подтверждённый сброс лимита и начисление дополнительного сброса.
- Компактная панель с новым плоским зелёным знаком, ручное обновление и запуск при входе.
- Управление подпиской в браузере по умолчанию без расширений и отдельного окна авторизации.

## Проверки и ограничения

27 автономных проверок пройдены локально. Universal-сборка содержит arm64 и x86_64; запуск локально проверен на Apple Silicon. Plus проверен на синтетических данных. Статус обеих архитектур доступен во вкладке Actions репозитория.

Приложение имеет ad-hoc подпись, без Developer ID и notarization: macOS может потребовать «Всё равно открыть» в настройках конфиденциальности и безопасности. Точное число оставшихся токенов сервис не возвращает. Автоматическая загрузка даты оплаты недоступна; карточка использует только ранее проверенную локальную запись для текущего аккаунта. Персональные записи не включены в релиз.
